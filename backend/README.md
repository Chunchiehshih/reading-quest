# 線上班級安裝步驟（Google 試算表＋Apps Script）

做完一次後，網站和繳交伺服器都在同一個網址，學生掃 QR code 就能闖關，不需要帳號。紀錄會存在你自己的 Google 試算表裡。大約 5 分鐘。

## 1. 建立試算表與 Apps Script
1. 到 Google 雲端硬碟新增一個 Google 試算表，例如取名「閱讀闖關紀錄」。
2. 在試算表上方選「擴充功能 → Apps Script」。
3. 把編輯器裡原本的 `Code.gs` 內容全部刪掉，貼上本資料夾的 `Code.gs`。
4. 把第一行附近的 `TEACHER_KEY` 改成你自己的教師密碼，例如 `const TEACHER_KEY = 'reading-5b-2026';`。
5. 左邊「檔案」旁邊按「＋ → HTML」，檔名輸入 `Index`（不用打 .html），把本資料夾的 `Index.html` 全部內容貼上。
6. 按儲存。

## 2. 部署成網頁應用程式
1. 右上角「部署 → 新增部署作業」。
2. 類型選「網頁應用程式」。
3. 「執行身分」選「我」；「誰可以存取」選「所有人」。
4. 按「部署」，第一次會要你授權（選自己的帳號 → 進階 → 前往專案 → 允許）。
5. 複製「網頁應用程式網址」（結尾是 `/exec`）。這就是網站網址。

> 學校的 Google Workspace 帳號有時只能選「學校網域內的使用者」。那樣學生要用學校帳號登入 Google 才能打開；想讓學生免登入，請改用個人 Gmail 帳號建立。

## 3. 上課使用
1. 用瀏覽器打開剛剛的網址，按「教師端 → 線上班級」，輸入教師密碼，按「儲存並讀取班級」。
2. 填班級名稱、年級，勾選要指派的關卡，按「建立並產生 QR code」。
3. 按「投影 QR code」。學生用平板或手機掃描，輸入座號和姓名就能開始。沒有相機的裝置可以在登入頁輸入班級代碼。
4. 學生闖完關按「完成並繳交給老師」。
5. 你按「讀取繳交紀錄」就會看到每位學生的分數、各層次答對情形，按「看歷程」能看每一題怎麼作答、用了幾次提示、錯題再挑戰和反思。按「在全班儀表板分析這班」可以看錯題排行和需要協助名單。
6. 所有紀錄也會出現在試算表的 `submissions` 工作表，可以直接在試算表裡篩選或匯出。

## 更新題目或網站
重新執行 `python3 build.py` 後，把新的 `Index.html` 貼回 Apps Script，再到「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」。網址不會變，舊的 QR code 仍然可以用。

## 資料與安全
- 學生端只會送出班級代碼、座號、姓名和闖關紀錄，沒有其他個人資料。
- 讀取全班紀錄、建立班級都需要教師密碼。密碼只存在你自己電腦的瀏覽器裡。
- 同一位學生（同班、同座號）重交同一關，會覆蓋前一次的紀錄。
