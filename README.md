# 閱讀闖關站

依 reading-literacy-quest skill（PIRLS 四層次：提取訊息、推論分析、詮釋整合、評估與評論）做成的學生自主闖關網站。純靜態網頁，不需要伺服器或資料庫。

## 打開方式
- 直接用瀏覽器打開 `index.html`（字型與注音需要網路）。
- 或用 `dist/reading-quest.html` 這個單一檔案版本（全部內容已內嵌）。
- 要放到網路上：把整個資料夾放到任何靜態主機（GitHub Pages、Netlify 等）。

## 資料
- `data/texts.json`：skill 內建 26 篇文章（低 8、中 8、高 10）。
- `data/quests/*.json`：關卡題組，格式依 skill 的 `references/website-json.md`。目前有：
  - `h06-q1` 高年級〈談將相和〉20 題＋補強題 12 題
  - `m03-q1` 中年級〈圈叉棋達人〉12 題＋補強題 6 題
  - `l01-q1` 低年級〈誰最棒〉8 題
- 新增題組：用 skill 出題後，把 JSON 放進 `data/quests/` 再執行 `python3 build.py`；或在網站「教師端 → 匯入題組」直接貼上（只存在那台電腦的瀏覽器）。

## 功能對照 skill 的闖關歷程
闖關地圖 → 任務說明 → 讀前暖身 → 閱讀文本（我讀完了）→ 四層闖關（依年段解鎖門檻）→ 錯題再挑戰（補回一半分數）→ 過關與反思。
- 答錯提示階梯：第一次顯示 hint 並標亮依據段落；第二次顯示該選項的回饋；第三次顯示答案與文本依據，記入錯題本。
- 年段設定：低年級注音（自動產生）與朗讀、一頁一題大選項、星星與貼紙；中年級「看文本」分割畫面、層次一二門檻；高年級畫線筆與筆記、每層門檻、提示扣半分、雷達圖、稱號；古文「語譯」在闖關時鎖住。
- 教師端：全班儀表板、錯題排行與最多人選的錯誤選項、需要協助名單、每題命題意圖／迷思／教學重點、匯入 JSON、匯出紀錄。

## 線上班級（QR code 登入與繳交）
老師在「教師端 → 線上班級」建立班級、投影 QR code；學生掃碼輸入座號姓名後闖關，完成後繳交，老師就能看到每位學生的闖關歷程。
後端是 Google 試算表＋Apps Script，網站也由同一個 Apps Script 網址提供。安裝步驟見 `backend/README.md`。
沒有設定線上班級時，網站仍可單機使用，紀錄只存在那台電腦的瀏覽器。

## 限制
- 高年級「挑戰關」（多文本比較、限時閱讀）尚未建置。
- 注音由 pinyin-pro 自動轉換並加上常見破音字修正，仍可能有誤。

## 重新打包
```
python3 build.py
```
會同時更新 `backend/Index.html`，貼回 Apps Script 後要部署新版本。
